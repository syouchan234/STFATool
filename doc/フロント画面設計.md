# フロント画面設計

React Router v6 で画面遷移を構成。
- `/login` → `LoginPage`
- `/staff` → `StaffListPage` (管理者)
- `/shift` → `ShiftCalendarPage`
- `/report` → `OutputPage`

MUI推奨コンポーネント
- `AppBar`, `Drawer`, `DataGrid`, `DatePicker`, `TimePicker`, `Modal`, `Button`, `TextField`

## シフト管理機能詳細
- **入力機能**: シフト作成時に分単位で時間を入力可能。TimePickerコンポーネントを使用し、秒単位は無視。
- **グラフUI**: 各登録者のシフト時間をJIRA風のタイムライングラフで確認可能。日次/週次/月次ビューでバーやガントチャート形式で表示。Rechartsライブラリを使用。
